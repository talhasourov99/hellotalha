# Mohammad Abu Talha — Portfolio

A responsive, motion-led portfolio built with Next.js, React, TypeScript, Framer Motion and custom CSS.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the VS Code terminal, run:

   ```powershell
   npm.cmd install
   npm.cmd run dev
   ```

4. Open http://localhost:3000.

To create a production build:

```powershell
npm.cmd run build
npm.cmd start
```

## Portfolio sections

- Intro and portrait-led hero
- About
- Filterable selected projects
- Ongoing thesis research
- Project notes
- Recognition and leadership applications
- Credentials and professional learning
- Education, volunteering and interests
- Contact

## Update your details

Edit the files in `data/` for profile, projects, achievements and journey information. Images and certificates are in `public/images/` and `public/certificates/`.

## V11 visual direction
The portfolio uses a burgundy, warm ivory and champagne palette with contrasting deep-burgundy research/contact sections. The portrait is presented in a clean rectangular frame, typography is enlarged, and the existing motion, project filtering, certificate links and CV download are retained.
