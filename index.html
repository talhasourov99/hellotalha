🔒 Smart Remote Gate Lock System

Designed a remote-operated gate lock using transistor-based switching circuits, a full-wave bridge rectifier for power supply, and a comparator circuit for tamper detection.

The system uses a Zener diode voltage regulator to maintain stable 5V operation and a relay driver stage to interface low-power control with the high-power gate motor.

Transistor SwitchingBridge RectifierZener DiodeComparatorRelay Driver
🌐 Enterprise Network Design

Designed a complete enterprise-grade network spanning two office sites. Features VLAN architecture for traffic segmentation, VLSM-based IP address planning, IPSec VPN tunnels for secure inter-site communication, and QoS policies for bandwidth prioritisation.

Topology diagrams were generated programmatically with Python and matplotlib, and the full network specification was documented in a formal technical report.

VLANVLSMIPSec VPNQoSCisco
⚙️ NASM Irrigation Control Programs

Developed and compared two x86 assembly implementations of irrigation control logic: a jump-based approach using conditional branches (JE, JNE, JG) and a branch-free alternative using CMOVcc instructions to eliminate branch misprediction penalties.

Included a full performance and readability analysis comparing both approaches, covering branch misprediction overhead and code maintainability trade-offs.
